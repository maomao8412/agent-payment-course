北京五环路复合廊道提质升级工程

（"动力环"项目）
项目名称北京五环路复合廊道提质升级工程（动力环）
项目类别基础设施 + 城市更新（复合类）
申报类别□ 2027年重点建设项目    ☑ 重点推进前期工作项目
建设地点北京市五环路沿线，涉及海淀、朝阳、丰台、石景山、大兴、亦庄、昌平7个行政区

一、项目建设背景和必要性

（一）建设背景

1. 国家战略层面：2026年10月1日，交通运输部、国家发展改革委、公安部、北京市人民政府、天津市人民政府、河北省人民政府等联合印发《加快建设现代化首都都市圈综合交通运输体系实施方案（2026—2030年）》，明确提出推动"八廊两环"交通主廊道建设，实施六环路扩能改造、"五环半""六环半"等项目，打造环状复合交通廊道。

2. 北京市层面：五环路全长98.6公里，串联七个行政区，是北京城市空间结构的重要环形骨架。当前五环路服务水平已达C/D级，通行能力接近饱和，沿线低效用地较多，与首都功能核心区和城市副中心的地位不匹配，亟需提质升级。

3. 工程基础：五环路健康工程（总投资25亿元）已于2026年启动设计招标，主要解决路面维修和桥梁加固问题。在此基础上进一步提质升级，将单纯的道路维修升级为复合廊道建设，具备良好的工程基础和政策时机。

（二）建设必要性

1. 是落实首都都市圈战略的具体行动。国家"八廊两环"战略已明确，北京作为核心城市需要拿出具体实施路径。五环路提质升级是"环状复合交通廊道"在北京市域内的核心载体和先行示范。

2. 是提升首都交通运行效率的迫切需要。五环路早高峰部分区段V/C比已接近0.9，拥堵常态化。提质升级后通行能力可提升20%以上，服务水平从C/D级提升至B/C级，显著改善市民出行体验和物流效率。

3. 是推动城市更新和高质量发展的重要抓手。五环路沿线分布着大量低效工业用地和产业空间。通过道路改造带动沿线产业升级和土地增值，可以撬动千亿级城市更新投资，形成"交通—产业—城市"的良性循环。

4. 是建设智慧城市和绿色交通的示范工程。智慧交通系统的建设可以作为北京"双智"城市建设的重要示范，推动车路协同、智慧管控等新技术的规模化应用。

二、建设规模与主要建设内容

项目总投资约180亿元，主要包括五大工程：

（一）道路本体提质工程（约55亿元）

  • 主路全幅路面大修（98.6公里）
  • 桥梁结构加固与外观提升（全线上百座桥梁）
  • 排水系统全面改造，提升内涝防治能力
  • 绿化景观品质提升，打造景观廊道
  • 照明系统智能化改造

（二）关键节点改造工程（约50亿元）

  • 14处关键节点立交优化和全互通化改造
  • 交织段治理和出入口间距调整
  • 部分节点增设匝道，提升转换效率
  • 远通桥等典型节点改造模式复制推广

（三）智慧交通建设工程（约25亿元）

  • 路侧感知设备规模化部署
  • 车路协同终端和路侧计算单元
  • 全路段智慧交通运行监测平台
  • 智慧通行、智能监测预警、干线数智管控系统
  • 数字孪生五环路（试点）

（四）TOD与站城融合工程（约35亿元）

  • 8个轨道微中心建设（五环与轨道交通交汇处）
  • 站城一体化枢纽改造
  • P+R停车场和B+R换乘系统
  • 公交场站优化提升

（五）产业配套与城市更新工程（约15亿元）

  • 沿线低效产业园区更新改造
  • 产业配套设施（人才公寓、公共服务、商业配套）
  • 桥下空间活化利用
  • 公共空间品质提升

四、实施进度安排

第一阶段：前期工作阶段（2026年底-2027年）

  • 项目立项和可行性研究
  • 规划方案编制和"多规合一"审查
  • 初步设计和概算审批
  • 列入市重点工程（前期工作项目）

第二阶段：启动实施阶段（2027年-2029年）

  • 道路本体工程全面开工
  • 2个示范节点改造开工
  • 智慧交通系统一期建设
  • 产业规划和城市更新方案编制

第三阶段：全面建设阶段（2029年-2031年）

  • 节点改造全面推进
  • TOD项目集中建设
  • 智慧系统全线覆盖
  • 低效用地批量更新

第四阶段：收尾运营阶段（2031年-2032年）

  • 景观绿化和慢行系统完善
  • 运营服务体系建立
  • 竣工验收和效果评估

五、经济社会效益分析

（一）经济效益

  • 年直接交通效益约174亿元（时间节约+燃油节约+事故减少）
  • 年新增产业产出约2190亿元（集聚效应+乘数效应+产业链联动）
  • 沿线土地增值约1800亿元（可达性+环境+集聚三重效应）
  • 新增就业约63万人
  • 年新增税收约657亿元（综合税负30%测算）

（二）社会效益

  • 显著改善沿线居民出行条件，提升生活品质
  • 提升城市形象，打造首都环形景观廊道
  • 推动城市更新，促进低效空间提质增效
  • 示范智慧交通和"双智"城市建设
  • 助力碳达峰碳中和目标（交通效率提升+绿色出行）

（三）战略价值

  • 落实首都都市圈"八廊两环"战略的北京行动
  • 打造北京高质量发展的环形经济引擎
  • 探索"交通+产业+城市"三位一体的城市更新新模式
  • 为全国超大城市环路改造提供北京经验

六、前期工作进展

1. 五环路健康工程已启动设计招标，正在推进中（可作为项目基础和启动期工程）

2. 相关节点改造（如远通桥）已有建成案例，可复制推广

3. 北京市智慧交通建设已有基础，可对接扩展

4. 沿线各区均有城市更新和产业发展需求，积极性较高
