# Agent Payment OS · 外行可视化课程

为商业计划书配套的交互式可视化讲解网页，面向外行深度理解A2A支付项目。

## 在线预览

https://maomao8412.github.io/agent-payment-course/

## 特色

- 📚 9大章节，从入门到价值全覆盖
- 🎴 翻转卡片、时间轴、阶段切换器等交互
- ❓ 手风琴式FAQ
- 🏔️ 价值金字塔可视化
- 📱 完全响应式，手机/平板/电脑均可
- 🌌 深色科技风设计
